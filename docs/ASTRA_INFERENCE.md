# Historical Astra inference: provenance and reproduction limits

Inference is a separate GPU workflow using official code and model assets. It is not launched here, and is not a dependency of synthetic validation. Consult the [pinned upstream instructions](https://github.com/EternalEvan/Astra/tree/3fb82e1939bfcf87d6e27a7da57d8b55ff9cb393) and the providers' current asset licenses before obtaining anything.

The retained pilot used one released conditioning scene, one fixed prompt (`A static garden scene with buildings and vegetation.`), opposite pure-yaw preset conditions (cam_type 2/3), seeds 17 and 29, and an A17 repeat. A and B are logical experimental conditions, not independently calibrated physical yaw truth. Nominal preset yaw was +/-0.03 radians per latent action step, with zero translation. Noise tensors, initial VAE latent and text embedding were matched and recorded. All three per-chunk noise draws were verified against serialized seeds, with action target rows/history masks checked against official indexing.

Recorded settings: sekai modality, initial_condition_frames=1, start_frame=0, frames_per_generation=8, total_frames_to_generate=24 latent frames, max_history_frames=100, bfloat16, 50 denoising steps, 832 x 480, 20 FPS, three experts/top-k one, text guidance 1.0, use_camera_cfg=False and camera_guidance_scale=2.0 argument. No icon overlay or ground-truth prompt was applied. The actual output had 97 decoded frames / 96 intervals; latent frame counts are not decoded pixel-frame counts. This differs from aspects of the paper's generation protocol.

Checkpoint loading and all five retained outputs succeeded. The planned larger 27-video design was not completed and is not reported as executed. The verified checks in `results/pilot_controls.json` are historical observations, not tests executed during publication preparation.

The published CLI has no seed argument in the inspected revision and uses global random noise. A matching nominal seed by itself does not reproduce the recorded matched-noise intervention. The original wrapper, prompt/noise execution logs, scene reference image, raw frame arrays and generated videos are excluded. Their private provenance records remain preserved. Consequently, this repository **does not claim exact end-to-end reproduction of the five original outputs from public inputs alone**. It exposes the instrument code, configurations and complete small numerical tables needed for diagnostic tests and coverage arithmetic.

For a future independent rerun: obtain official assets under verified terms, use a separately reviewed matched-noise wrapper, preserve decoded frames and noise/latent/embedding hashes, verify actual action tensors and parser values, and freeze the protocol before interpreting outcomes. The inspected parser's boolean handling makes literal `False` strings unsafe as substitutes for actual False defaults; follow the pinned code. This is a future workflow description, not an executed experiment or permission to launch one.

No Astra implementation, official weight or conditioning image is bundled. `provenance/checkpoints.json` records model revisions and hashes for provenance only; those identifiers confer no redistribution permission.
